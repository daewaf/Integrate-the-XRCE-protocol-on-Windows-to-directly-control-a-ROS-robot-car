# FishBot Windows 原生控制 · 启动与关闭手册

适用项目：`xrce_windows_agent`（纯 Python XRCE-DDS agent）
更新日期：2026-10-26

## 1. 这套工具是什么

不安装 ROS2、不经过 WSL Ubuntu，在 Windows 上用 Python 直接和 FishBot 主控板完成
XRCE-DDS 协议握手、实体创建、Twist 下发与 odom/imu 数据解析。

```
WASD 终端 ──TCP 8898──> agent ──UDP 8888──> 车主控板
                          <── odom / imu ────┘
```

| 组件 | 作用 |
|---|---|
| `xrce/agent.py` | XRCE-DDS agent（协议转换核心） |
| `tools/teleop_wasd.py` | 终端 WASD 遥控 |
| `start_fishbot.py` | 一键启动 agent + WASD，并在退出时关闭 agent |

## 2. 前提条件

1. Windows 已安装 Python 3.10（本项目实测版本）。
2. 主控板 WiFi 与电脑在同一网络。
3. 主控板“上位机 IP” = 电脑当前 WLAN 地址，端口 **8888**。
4. 电脑上 **不要**同时运行 WSL/Docker 的 `micro_ros_agent`（会占用 8888）。

端口占用：

| 端口 | 协议 | 用途 |
|---|---|---|
| 8888 | UDP | XRCE-DDS（主控板 ↔ agent） |
| 8898 | TCP | 本机控制口（WASD ↔ agent） |

## 3. 一键启动（推荐）

打开 PowerShell：

```powershell
cd "C:\Users\kw188\Desktop\ros小车\xrce_windows_agent"
python start_fishbot.py
```

启动流程：

1. 打印本机 IP（这个地址要填到主控板的“上位机 IP”）。
2. 后台启动 agent（隐藏窗口，日志写入 `agent_runtime.log`）。
3. 等待 TCP 8898 就绪。
4. 当前终端进入 WASD 遥控。
5. 退出时自动关闭 agent。

只检查环境、不进入遥控：

```powershell
python start_fishbot.py --check
```

> 如果检测到已经有 agent 在 8898 上运行，会直接复用；退出遥控时不会关闭被复用的 agent。

### 推荐启动顺序

1. 先运行 `python start_fishbot.py`（或先单独启动 agent）。
2. 再给小车断电重启。
3. 等 3–5 秒，主控板完成握手。
4. 开始 WASD 遥控。

先启动 agent 再上电，可以保证主控板建立完整的订阅会话；反向操作也能连，
但会话状态不完整时可能出现“能收 odom、指令不生效”的情况。

## 5. 遥控按键

| 按键 | 动作 | 默认值 |
|---|---|---|
| `W` | 前进 | 0.05 m/s |
| `S` | 后退 | 0.05 m/s |
| `A` | 左转 | 0.3 rad/s |
| `D` | 右转 | 0.3 rad/s |
| `空格` | 立即停车 | — |
| `X` 或 `Ctrl+C` | 停车并退出 | — |

行为说明：

- 遥控直接轮询按键的物理状态，不依赖 Windows 键盘连发。
- 按住方向键时每 0.1 秒刷新一条 0.3 秒的运动指令，连续运动无断档。
- 松开按键立即发送停车指令。
- agent 内部只有一个 20 Hz 发布线程；按键只更新目标速度，不会堆积线程。

## 6. 如何关闭

### 6.1 一键启动方式

在 WASD 界面按 `X` 或 `Ctrl+C`。agent 会在后台自动关闭。

### 6.2 单独启动的 agent

在 agent 所在终端按 `Ctrl+C`。这是最干净的退出方式。

### 6.3 终端已关闭 / 进程残留

PowerShell 按端口关闭：

```powershell
Get-NetUDPEndpoint -LocalPort 8888 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

或按命令行匹配：

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*xrce.agent*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

确认已经关闭：

```powershell
Get-NetUDPEndpoint -LocalPort 8888
```

没有输出即表示 8888 已释放。

### 6.4 切换回 WSL / Docker 方案

1. 先关闭 Windows 上的 Python agent（否则 8888 冲突）。
2. 在 WSL 中执行：

```bash
docker start micro_ros_agent
```

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| `agent 启动失败` | 查看 `agent_runtime.log`；确认 8888 未被 Docker/WSL agent 占用 |
| 8898 被占用 | 换控制口：`python -m xrce.agent --control-port 8897`，并同步修改 `teleop_wasd.py` 的 `PORT` |
| 车不动，但终端返回 OK | 确认“上位机 IP”正确；先启动 agent 再重启小车；查看 agent 日志是否有 `WRITE_DATA` |
| `未收到 /odom` | 主控板未连上或会话不完整，先断电重启小车 |
| 轮子一顿一顿 | 确认用的是本版代码（单线程 20 Hz 发布），不要同时开多个 agent |
| 中文乱码 | 使用 Windows Terminal；脚本已自动切换 UTF-8 代码页 |
| 会话反复重建 | 确认是本项目最新版（会话内 INFO 应答的 `impl` 字节必须为 `01`） |
